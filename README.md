# configuration-management-p1-2025-2
Implement version management in a collaborative development project using Git, working with branches, merging changes, and resolving conflicts in a multi- developer environment. Students can choose between a backend web application or a frontend web application project based on their preference.

#### Frontend
- Katherine Forero: Implements the task list display and connects it to the backend API (GET /tasks).
- David Ramirez: Adds the “Add New Task” form and handles submission using JavaScript (POST /tasks).
- Gabriel Sanchez: Implements task completion functionality (marking tasks as done) and updates the UI dynamically.

#### Backend
- Katherine Forero: Implements the GET /tasks endpoint to retrieve all tasks.
- David Ramirez: Develops the POST /tasks endpoint to add a new task.
- Gabriel Sanchez: Creates the PUT /tasks/:id endpoint to mark tasks as completed.
