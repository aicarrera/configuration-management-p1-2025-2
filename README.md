# configuration-management-p1-2025-2
Implement version management in a collaborative development project using Git, working with branches, merging changes, and resolving conflicts in a multi- developer environment. Students can choose between a backend web application or a frontend web application project based on their preference.

Integrantes:
- Cesar Mera (Líder)
- Juan (Frontend - Lista)
- Paul (Frontend - Alta)
- Kevin (Backend - API)

## 👥 Roles y tareas
| Nombre | Rol | Rama | Tareas principales |
|--------|------|------|-------------------|
| Cesar Mera | Líder | group-2 | Revisión, merges, release v1.0.0 |
| Juan | Frontend 1 | juan/group-2 | Lista de tareas (GET /tasks) |
| Paul | Frontend 2 | paul/group-2 | Alta y completar tareas (POST /tasks, PUT /tasks/:id) |
| Kevin | Backend | kevin/group-2 | API REST (GET, POST, PUT) |
